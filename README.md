# IRONFIT — Premium Android Fitness & Bodybuilding Application

IRONFIT is a native Android bodybuilding and fitness application featuring a modern dark design system, comprehensive workout tracking, exercise database, and personalized progress visualization.

## 🚀 Key Features

- **Dark Theme Fitness Design**: Sleek black, charcoal, and crimson red palette (`#101010`, `#E53935`).
- **Exercise Library**: Over 20 comprehensive exercises categorized by muscle groups (Chest, Back, Shoulders, Legs, Arms, Abs) with step-by-step instructions.
- **Interactive Workout Tracker**: Real-time session tracker supporting sets, reps, load in kg, completion toggles, and rest countdown timers.
- **Workout Programs**: Built-in plans including Full Body, Upper/Lower, and Push-Pull-Legs (PPL).
- **Progress Tracking & Analytics**: Weight logging history, interactive cubic-Bézier weight progression charts, and personal records (PRs).
- **Local Persistence**: Powered by SQLite architecture for offline-first reliability.

## 🛠️ Technology Stack

- **Platform**: Native Android (SDK 26+)
- **Language**: Java 17
- **UI Architecture**: XML Layouts with Material Design Components
- **Database**: SQLite (Room-compatible architecture)
- **Charts**: MPAndroidChart
- **Build System**: Gradle 9.5
